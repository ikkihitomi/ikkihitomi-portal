OFFICIAL RELEASE

一箕地区ポータル Ver1.00 正式リリース

2026年8月1日

概要

2026年8月1日、 一箕地区ポータル Ver1.00を正式公開し、 運用を開始しました。

「人と人、地域と未来をつなぐ」を基本理念として、 一箕地区の行事予定、お知らせ、防災情報、 町内会紹介、地域ブログなどを集約した、 地域情報の新しい窓口としてスタートしました。

本サイトは、単に地域情報を掲載するだけでなく、 公式LINE、住民登録、フォトコンテスト応募、 WordPress、Supabaseを連携させた、 地域運営のための情報基盤として構築しています。

主な公開機能

  • 地域のお知らせ掲載
  • 行事予定・イベント情報掲載
  • 町内会紹介
  • 地域団体紹介
  • 地域ブログ
  • 防災情報
  • 施設予約案内
  • 公式LINE友だち追加
  • LIFFによる住民登録
  • 一箕地区フォトコンテスト2026
  • フォトコンテストWeb応募
  • Google Analyticsによるアクセス解析
  • Google Search Console対応

システム構成

  • GitHubによるソースコード・バージョン管理
  • Vercelによる公開環境・自動デプロイ
  • Supabase Database
  • Supabase Authentication
  • Supabase Storage
  • Supabase Edge Functions
  • WordPressによる地域ブログ・町内会紹介
  • LINE Messaging API
  • LIFFによる住民登録・フォトコン応募
  • Google Analytics 4
  • Google Search Console
2026年8月1日、正式運用開始

一箕地区ポータルは、この日を新たな出発点として、 地域の皆さまとともに育てていく 地域情報基盤として正式に運用を開始しました。

今後も住民の皆さまから寄せられるご意見やご要望を 一つひとつ検討しながら、 継続的な改善と機能拡張を進めてまいります。
